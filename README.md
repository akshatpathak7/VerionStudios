# Verion Studios

A single-page video editing and digital services studio website, built with React and the Sites Vinext starter.

## Update content

Edit `app/studio.ts` to change the service copy, logo path, and contact email. Leave email blank to show the honest pending-contact state. Replace `public/verion-mark.svg` with the final logo or update its configuration path. The cinematic image is AI-generated concept imagery, not client work.

## Development

Run `npm run dev` for the local preview and `npm run build` for a production build. Motion can be paused on the page and automatically stops when reduced motion is preferred.
